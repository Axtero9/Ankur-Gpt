# AnkurGPT // (1)
### *Pure Conversational Intelligence Engineered with Tactile Precision*

AnkurGPT is a next-generation AI conversational workspace inspired by the conversational flow of **ChatGPT**, the materiality and optical depth of **Apple**, the utilitarian document clarity of **Notion**, and the raw, transparent monochrome industrial design of **Nothing**.

## ✨ Features & Capabilities

### 1. ⚡ Nothing OS Aesthetics
- **NDot Matrix Typography:** Digital display headers and telemetry counters.
- **Glyph Indicator:** Signature Nothing Red (`#E01020`) LED status dot that pulses during inference.
- **Hardware Telemetry Widget:** Real-time token counter, model latency, and system nominal state.
- **Technical Dot-Grid:** Optional subtle geometric dot grid background texture.

### 2. 🍏 Apple Tactility & Optical Balance
- **Frosted Glass Blur:** Translucent background blurs (`backdrop-blur-2xl`) with specular micro-borders.
- **Dynamic Status Capsule:** Central floating pill showing current model, status, and rapid switcher.
- **Acoustic Haptics:** Pure Web Audio API synthesized micro-clicks on buttons and send interactions (zero asset latency).
- **Smooth Spring Micro-interactions:** Tactile button states and smooth drawer transitions.

### 3. 📝 Notion Utilitarian Simplicity
- **Instant Slash Commands (`/`):** Trigger quick templates directly in the input bar:
  - `/code` — TypeScript & React architecture generator
  - `/prd` — Structured Product Requirements Document
  - `/design` — Design system & aesthetic deconstruction
  - `/explain` — First-principles deep breakdown
  - `/summarize` — Executive synthesis & action items
- **Notion-style Callout Blocks:** Highlighted alerts (`[!NOTE]`, `[!TIP]`, `[!WARNING]`).
- **Collapsible Sidebar:** Grouped chronology (Today, Yesterday, Previous Days, Pinned).
- **Spotlight Command Palette (`⌘K` / `Ctrl+K`):** Global fuzzy search for conversations, models, and actions.

### 4. 💬 ChatGPT Conversational Muscle
- **Autonomous Local Engine:** Ready immediately out of the box with zero configuration! Generates rich code, analysis, and explanations with authentic chunk-by-chunk streaming.
- **API Key Support:** Plug in your OpenAI API key (GPT-4o) or Google Gemini API key in Settings for live cloud inference.
- **Markdown & Syntax Highlighting:** Clean code blocks with language indicators and one-click clipboard copying.
- **Voice Dictation & Text-to-Speech:** Built-in Web Speech API voice input and speech synthesis audio playback.
- **Data Portability:** 1-click export of any conversation as formatted Markdown (`.md`) or raw JSON (`.json`).

## 🚀 Quick Start

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `⌘K` or `Ctrl+K` | Open Global Command Palette |
| `⌘N` or `Ctrl+N` | Create New Chat Session |
| `⌘\` or `Ctrl+\` | Toggle Sidebar Navigation |
| `/` in message box | Open Notion Slash Command Menu |
| `Enter` | Send message |
| `Shift + Enter` | Multi-line break |
| `Esc` | Close modal or menu |

## 🛠️ Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + PostCSS + Custom Dot Matrix & Frosted Glass Utilities
- **Icons:** Lucide React
- **Audio:** Web Audio API Native Synthesizer
- **Voice:** Web Speech API (Dictation & Text-to-Speech)
- **Storage:** LocalStorage browser persistence
